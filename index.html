Research

I'm interested in kernel security. My research is about linux kernel vulnerability exploitation.
BridgeRouter: Automated Capability Upgrading of Out-Of-Bounds Write Vulnerabilities to Arbitrary Memory Write Primitives in the Linux Kernel
Dongchen Xie, Dongnan He, Wei You, et al.
IEEE S&P, 2025

In this paper, we propose a practical approach that enables arbitrary memory writes from kernel OOB vulnerabilities with limited capabilities. Our method leverages two special kinds of kernel objects to upgrade the capability from an uncontrolled overwrite to a controlled overwrite, ultimately achieving arbitrary memory write.

ACM ISSTA, 2024

In this paper, we propose a novel and practical path exploration strategy that focuses on the coverage of define-use relations in the subject binary. We develop a fuzzing approach for exploring these define-use relations in a progressive and self-supervised way.

/* Capability upgrade: OOB write -> Arbitrary write */
static int trigger_oob_write(int fd, size_t offset) {
    struct bridge_obj *obj;
    void *spray_buf;

    /* Step 1: Spray vulnerable slab cache */
    spray_buf = heap_spray(KMALLOC_256, NUM_SPRAY);

    /* Step 2: Trigger OOB via ioctl */
    ioctl(fd, VULN_IOCTL, &overflow_data);

    /* Step 3: Upgrade to arbitrary write */
    obj = find_bridge_object(spray_buf);
    obj->write_target = (void *)MODPROBE_PATH;
    trigger_controlled_write(obj, payload, sizeof(payload));

    return 0;
}
